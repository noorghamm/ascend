# Ascend

*Find your level.*

A study-buddy board for the University of Glasgow library. Post when you're in,
which zone you're on (green / amber / red), and how long you're staying — so
people who like studying with company can find each other.

No accounts. Posts are verified by a link sent to your student email.

**Stack:** Django REST Framework (API) · React + Vite (frontend)

**Status:** work in progress — my first React project, built to solve a
problem I actually have.
